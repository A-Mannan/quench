# Promo brief — Quench

## One-sentence message

Deposit a yield-bearing INJ LST, mint qINJ against it, and let Wellspring's yield pay the debt down to zero — simulated, testnet only, contracts not deployed.

## Audience

Injective ecosystem builders and reviewers who want to see the loop in 60 seconds without reading the simulator code. Secondary: anyone landing from a social post with sound off.

## Treatment

Look: the product's own v9 blue system. Night lab `#090B0F`/`#151A24` for the film, day paper `#EDF0F6` for the trust chapter. Hairline rules, cobalt `#2E5BFF`-family accent reserved for the live numbers, Schibsted Grotesk + JetBrains Mono. The app UI is the protagonist; the camera pushes into real captures, never redraws them. Borrowed grammar from lemo-opuscar *Dark Tech Keynote* (one accent, hairline grid, snap-grid motion) read as direction only — no code or footage copied.

Continuity: one position throughout (deposit → mint → harvest → withdraw) and one labelled second run for redemption, because redeeming 10 qINJ leaves only 80 to burn and zero-debt would be unreachable in the same session.

Music: original synthesized score at 120 BPM (2 s per bar). No third-party track. No voiceover.

Disclosure: "Simulated demo · contracts not deployed" is in the top instrument bar for the whole film and on the end card.

## Format

- 16:9, 1920×1080, 30 fps, H.264, **40 s** (tightened from 60 s, 2026-11-09 — the cut keeps only the beats the voice carries).
- 9:16 cut: **dropped by user** — 16:9 only is delivered.
- Voiceover: local Kokoro-82M `af_heart` (no API key — AGENTS.md hard rule forbids accepting one; user offered Fish Audio/ElevenLabs, declined). 8 lines, music ducked −10 dB under it.
